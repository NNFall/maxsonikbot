## Риски и ограничения
- В MAX API нет полноценного аналога Telegram command scope для “команды только админам” в UI.
- `set_my_commands` в `maxapi` работает, но помечен библиотекой как deprecated относительно официальной swagger MAX.
- Запуск нескольких инстансов с одним токеном приводит к дублированию ответов.
